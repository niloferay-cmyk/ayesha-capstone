# ADR-0001: Capstone Framing — ayesha-capstone

- **Status:** Draft v1
- **Date:** 20-08-2026
- **Author:** Ayesha Niloufer

## Context

This capstone aims to build a knowledge assistant that can answer questions based on a specific set of documents, rather than relying only on the LLM's general knowledge. So far, I have only implemented a basic LLM call where a user sends a question and receives a response; the next step is to build the RAG pipeline to retrieve relevant information from the document corpus.

## Decision – Solution Framing Canvas

| Box | Your answer |
|-----|-------------|
| **Inputs** | User sends a text question to the assistant. Later, the system will also take relevant documents as a knowledge source.
| **Outputs** | A text answer generated by the LLM. In the future, the RAG system should provide an answer grounded in the relevant documents, potentially with citations.|
| **Tools** | Currently, the OpenAI LLM/API. As the RAG pipeline develops, this will include document parsing/chunking, an embedding model, and a vector database/retriever.|
| **Memory** |Currently, none. Each question is handled independently; previous conversations are not retained. |
| **Autonomy level** |Currently closer to a basic chatbot/LLM application than an agentic system because it only receives a question and generates an answer. The planned RAG system will add retrieval, but it will still have limited autonomy. |
| **Decision boundaries** | Currently, the LLM generates the response based on the user's question and its available knowledge. It does not make business decisions or take external actions; decisions requiring human judgment should remain with a human. |

## Consequences

- **Positive:** Simple to implement and provides quick responses to user questions.
- **Negative / risks:**The current system is not grounded in the organization's documents and may produce inaccurate or hallucinated answers.
- **Things we'll re-visit:** Build the RAG pipeline so answers can be based on relevant documents rather than only the LLM's general knowledge.
